# SESSION SUMMARY
<<session_summary>>

# YOUR TASK
Convert the session summary above into a single activity object formatted as valid JSON. The activity will be saved to a Firebase activities collection and displayed in a React frontend.

{
  "name": "Short, specific activity name. E.g. 'First boxing class at Rumble Gym'. Max 60 chars.",

    {

}

# RULES
- name: specific and concrete. Include the real location or activity type if known.
- type: match exactly to one of the six options listed. Do not invent new types.
- scheduledDate: leave as null — the frontend will let the user pick the date.
- why: pull directly from what they said in the session. Do not rephrase it abstractly.
- preAnxiety: use the anxiety rating from phase 4. If not available, use 6 as default.
- actionSteps: 2–4 steps maximum. These are the micro-steps to reduce starting friction. Each step should be doable in under 5 minutes.
- sessionInsight: this is the CBT reframe the user arrived at. Write it as something they would say to themselves, not as therapy advice.
- Do not add any fields not listed above.
- Do not include explanation, preamble, or markdown. Return only the raw JSON object.
